# `data/` — runtime data volume

This directory is mounted as `/data` inside the backend container (via `docker-compose.yml`). All of it is generated by the offline pipeline or written at runtime — **nothing here is hand-edited**. Most files are git-ignored; only `data/.gitkeep`, `data/schema/labels.yaml`, the `data/external/*/SOURCES.lock` provenance files, and this README live in the repo.

## How to refresh

| Goal | Command |
| --- | --- |
| Build a fresh training package from approved sources | `make data-prep DATASET_VERSION=<v> FEATURE_VERSION=<v> OWNER=<who>` |
| Smoke a single seed against an existing package | `make train-smoke TRAINING_PACKAGE_ID=<id> SEED=11 OWNER=<who>` |
| Full official batch across `{11, 29, 47, 71, 97}` | `make train-batch TRAINING_PACKAGE_ID=<id> OWNER=<who>` |
| End-to-end smoke (toy snapshot + tests) | `make verify` |

`make` will refuse to start if `DATASET_VERSION` / `FEATURE_VERSION` / `TRAINING_PACKAGE_ID` is missing — that's intentional; don't paper over it.
